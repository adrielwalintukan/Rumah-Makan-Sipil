## Pembagian Task

### Task 1: Halaman Error & 404 Bermerek (`app/error.tsx` & `app/not-found.tsx`)
- Buat `app/error.tsx`: Root Error Boundary Client Component dengan identitas visual Rumah Makan Sipil (judul Fraunces, warna hijau tua `green-900`, latar krem `cream-50`, ikon kuliner/peringatan hangat, teks ramah santai tanpa error code seram, tombol "Coba Lagi" yang memanggil `reset()`, dan link "Kembali ke Beranda").
- Buat `app/not-found.tsx`: Halaman 404 global bermerek ("Halaman Tidak Ditemukan", ilustrasi ramah, tombol "Lihat Menu").
- Tambahkan unit test di `app/error.test.tsx` dan `app/not-found.test.tsx`.

### Task 2: Sistem Toast Notification Bermerek & Feedback Admin
- Buat sistem toast ringan di `components/ui/toast.tsx` dan `lib/use-toast.ts` sesuai spesifikasi `docs/design-system.md §6.8`:
  - Muncul di atas layar (`fixed top-4 inset-x-0 mx-auto max-w-sm z-50`), auto-dismiss setelah 3 detik, tombol tutup manual, `aria-live="polite"`.
  - Varian: `success`, `danger`, `default` dengan warna sesuai token brand (`green-700`, `danger`, `line`).
- Pasang `<Toaster />` di root `app/layout.tsx`.
- Hubungkan toast notification pada aksi penting dashboard admin:
  - Simpan profil & keamanan di `app/admin/(dashboard)/pengaturan/page.tsx`.
  - Tambah, edit, dan hapus menu di `components/admin/menu/`.
  - Tambah, edit, dan hapus pengeluaran di `components/admin/finance/`.
- Tambahkan unit test untuk toast di `components/ui/toast.test.tsx`.

### Task 3: Panel Keranjang di Kanan untuk Desktop (`design-system.md §7`)
- Sesuai `docs/design-system.md §7`:
  - Di layar desktop (`>= 1024px` / `lg:`): Konten menu berada di kiri/tengah (maks 720px), dan keranjang ditampilkan sebagai panel kanan yang sticky (`sticky top-20 w-80 shrink-0`).
  - Buat komponen `DesktopCartPanel` di `components/pelanggan/desktop-cart-panel.tsx`.
  - Di desktop, tampilkan daftar item keranjang, subtotal, tombol lanjut ke pembayaran, serta empty state ramah jika belum ada item.
  - Sembunyikan bar keranjang bawah (`CartBar`) di desktop (`lg:hidden`).
- Tambahkan unit test di `components/pelanggan/desktop-cart-panel.test.tsx`.

### Task 4: Skeleton Loading Terstruktur untuk Alur Pelanggan
- Buat komponen skeleton yang merefleksikan layout sebenarnya pada halaman pelanggan:
  - `CartSkeleton` di `app/(pelanggan)/keranjang/page.tsx`.
  - `CheckoutSkeleton` di `app/(pelanggan)/checkout/page.tsx`.
  - `OrderTrackSkeleton` di `app/(pelanggan)/pesanan/[token]/page.tsx`.
- Tambahkan unit test untuk memastikan skeleton merender atribut `aria-busy="true"` dan kelas latar `cream-100`.

### Task 5: Audit Aksesibilitas, Safe Area, Reduced-Motion, & Pencegahan Auto-Zoom iOS
- Di `app/globals.css`:
  - Tambahkan dukungan media query `@media (prefers-reduced-motion: reduce)` untuk mematikan animasi dan transisi non-esensial.
  - Pastikan variabel dan aturan `env(safe-area-inset-bottom)` terpasang rapi pada elemen sticky bawah.
- Di seluruh elemen form input (`components/ui/input.tsx`, dsb.):
  - Pastikan ukuran font input minimal 16px (`text-base`) agar browser iOS Safari tidak melakukan zoom otomatis saat pengguna mengetuk kolom input.
- Pastikan semua tombol dan link memiliki `focus-visible:ring-2 focus-visible:ring-green-700 focus-visible:outline-none`.

### Task 6: Verifikasi E2E Playwright, Sinkronisasi Dokumen, & CI Gate
- Tambahkan E2E test di `e2e/polish.spec.ts` untuk memverifikasi desktop cart panel di viewport 1280px dan mobile cart bar di viewport 375px, serta navigasi 404 page.
- Jalankan pemeriksaan kualitas lengkap: `npm run lint`, `npm run typecheck`, `npm test`, dan `npm run build`.
- Sinkronkan `docs/roadmap.md` dengan mencentang item M6 yang relevan.
