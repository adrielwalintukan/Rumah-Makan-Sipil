# Rencana Implementasi: Poster QR Cetak & Unduh PNG (Issue #23)

**Milestone:** M6 - Poster QR, Polish, Rilis  
**Issue Terkait:** #23 ([M6] Poster QR: cetak (A4/A5) + unduh PNG)  
**Dokumen Desain:** `docs/superpowers/specs/2026-10-23-m6-qr-poster-design.md`  

---

## Gambaran Umum

Mengimplementasikan fitur pembuatan poster QR siap cetak dan siap unduh di rute `/admin/qr` untuk pemilik warung Rumah Makan Sipil. Fitur ini memungkinkan pemilik mencetak poster ukuran A4 (dinding/kasir) atau A5 (tenda meja) secara langsung dari browser atau mengunduh file PNG resolusi tinggi (300 DPI) untuk dicetak di percetakan luar.

---

## Rincian Task

### Task 1: Dependensi `qrcode` & Modul Utilitas `lib/qr.ts` (TDD)

- **Deskripsi:**
  - Pasang paket `qrcode` dan `@types/qrcode`.
  - Terapkan pola TDD untuk membuat unit test di `lib/qr.test.ts` (RED).
  - Implementasikan `lib/qr.ts` (GREEN):
    1. `getStoreCanonicalUrl(fallbackOrigin?: string): string`: Resolusi URL kanonikal toko dari `process.env.NEXT_PUBLIC_SITE_URL` dengan fallback aman ke `fallbackOrigin` atau `http://localhost:3000`.
    2. `generateQrDataUrl(text: string, options?: QrOptions): Promise<string>`: Menghasilkan data URL PNG dari QR code menggunakan `qrcode.toDataURL`.
    3. `renderPosterToCanvas(config: PosterRenderConfig): Promise<HTMLCanvasElement>`: Menggambar poster beresolusi tinggi (300 DPI) ke elemen Canvas offscreen untuk ekspor gambar tajam.
    4. `exportPosterToPngBlob(config: PosterRenderConfig): Promise<Blob>`: Mengonversi hasil canvas menjadi PNG Blob.
    5. `triggerDownload(blob: Blob, filename: string): void`: Membantu browser memicu unduh file.
- **File Terdampak:**
  - `package.json`
  - `package-lock.json`
  - `lib/qr.ts` (baru)
  - `lib/qr.test.ts` (baru)
- **Verifikasi:**
  - `npx vitest run lib/qr.test.ts`
  - `npm run lint` & `npm run typecheck`
- **Commit:**
  - `feat(qr): instalasi qrcode dan modul utilitas generator poster kanonikal`

### Task 2: Komponen Visual `<PosterCard>` & CSS `@media print`

- **Deskripsi:**
  - Buat komponen visual `components/admin/qr/poster-card.tsx`:
    - Menerima prop: `size: "a4" | "a5"`, `storeName: string`, `tagline: string`, `qrDataUrl: string`, `siteUrl: string`.
    - Menggunakan aspek rasio ISO 216 (`aspect-[210/297]`).
    - Desain poster:
      - Emblem inisial RMS + Nama Toko (font display Fraunces) + Tagline.
      - Kotak QR code kontras tinggi berbingkai bersih dengan badge "SCAN UNTUK PESAN".
      - Panduan 3 langkah mudah bagi pelanggan:
        1. Buka kamera / scan QR.
        2. Pilih menu makanan & minuman.
        3. Bayar di kasir / QRIS DANA & makanan diantar.
      - Footer URL toko yang mudah dibaca.
  - Tambahkan aturan CSS `@media print` khusus poster di `app/globals.css` atau modul styling:
    - Sembunyikan elemen admin (`AdminNav`, sidebar, header, tombol kontrol, dsb).
    - Pastikan elemen poster tercetak pas 1 halaman penuh tanpa terpotong ke halaman berikutnya.
    - Properti `-webkit-print-color-adjust: exact; print-color-adjust: exact;` aktif.
- **File Terdampak:**
  - `components/admin/qr/poster-card.tsx` (baru)
  - `app/globals.css` (update aturan `@media print`)
- **Verifikasi:**
  - `npm run lint` & `npm run typecheck`
- **Commit:**
