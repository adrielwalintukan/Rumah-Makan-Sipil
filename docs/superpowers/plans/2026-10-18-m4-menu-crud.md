# [M4] Kelola Menu & Kategori Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menyediakan sistem kelola menu bagi pemilik warung untuk menambah, mengubah, mengurutkan, menghapus lunak menu (`is_active = false`), serta mengubah status ketersediaan (Habis) secara cepat langsung dari antarmuka web, tanpa bantuan developer.

**Architecture:** Route Handlers Next.js App Router (`/api/admin/categories`, `/api/admin/menu`) yang divalidasi dengan Zod dan dilindungi autentikasi pemilik (`getAdminUser`). Halaman web berbasis Server Components (`/admin/menu`, `/admin/menu/baru`, `/admin/menu/[id]`) dengan Client Components responsif yang mematuhi token desain `design-system.md`, target sentuh HP ≥ 44px, dan aksesibilitas keyboard tanpa dependency pihak ketiga.

**Tech Stack:** Next.js 16 (App Router), TypeScript strict, Tailwind CSS, Supabase Postgres (RLS), Zod, Vitest, Playwright.

**Spec:** Issue #16, `docs/PRD.md` (US-13, D6), `docs/user-flows.md` §5, `docs/architecture.md` §4, `AGENTS.md` §8.4.

## Global Constraints

- Validasi harga dan mutasi di server; nominal selalu `integer` Rupiah `check (price >= 0)`.
- Hapus menu selalu menggunakan hapus lunak (`is_active = false`) agar integritas riwayat pesanan (`order_items`) tetap terjaga.
- Target sentuh interaktif pada HP (360 px) wajib ≥ 44px (`min-h-[44px]`).
- Kontras warna teks memenuhi standar WCAG AA (≥ 4.5:1 untuk teks normal).
- Menggunakan Server Component dengan `await connection()` untuk rute dinamis dashboard admin.

```typescript
// lib/admin-menu-schemas.ts
import { z } from "zod";

export const categorySchema = z.object({
  name: z.string().trim().min(1, "Nama kategori wajib diisi").max(50, "Nama kategori maksimal 50 karakter"),
  sort_order: z.number().int().min(0).default(0),
});

export type CategoryInput = z.infer<typeof categorySchema>;

export const menuItemSchema = z.object({
  category_id: z.string().uuid("Kategori tidak valid"),
  name: z.string().trim().min(1, "Nama menu wajib diisi").max(100, "Nama menu maksimal 100 karakter"),
  description: z.string().trim().max(500, "Deskripsi maksimal 500 karakter").optional().default(""),
  price: z
    .number({ invalid_type_error: "Harga harus berupa angka" })
    .int("Harga harus berupa bilangan bulat Rupiah")
    .min(0, "Harga tidak boleh negatif"),
  is_available: z.boolean().default(true),
  sort_order: z.number().int().min(0).default(0),
});

export type MenuItemInput = z.infer<typeof menuItemSchema>;

export const quickToggleAvailabilitySchema = z.object({
  is_available: z.boolean(),
});

export const reorderSchema = z.object({
  items: z.array(
    z.object({
      id: z.string().uuid(),
      sort_order: z.number().int().min(0),
    })
  ).min(1, "Daftar urutan tidak boleh kosong"),
});

export type ReorderInput = z.infer<typeof reorderSchema>;
```
